# Sistema de Evaluación - Registro de Clientes

Proyecto desarrollado para la asignatura **Programación de Aplicaciones de Escritorio**.

## Descripción

El proyecto consiste en una aplicación de escritorio desarrollada en JavaFX para gestionar el registro y consulta de clientes.

La aplicación permite al usuario iniciar sesión, acceder a un menú principal, registrar los datos de nuevos clientes y consultar la información registrada. Durante el proceso se utilizan diferentes controles gráficos de JavaFX, navegación entre ventanas y paso de información entre formularios.

El sistema fue desarrollado con el objetivo de aplicar los conocimientos adquiridos sobre interfaces gráficas, eventos, formularios y manejo de datos dentro de una aplicación de escritorio.

## Funcionalidades principales

- Inicio de sesión.
- Menú principal de navegación.
- Registro de clientes.
- Selección del tipo de cliente y ciudad.
- Selección de fecha de nacimiento.
- Selección del tipo de solicitud mediante RadioButton.
- Selección de servicios de interés mediante CheckBox.
- Selección y visualización de fotografía del cliente.
- Validación de los datos ingresados.
- Consulta de clientes registrados.
- Navegación entre diferentes ventanas.
- Paso de información entre formularios.
- Uso de mensajes de información, advertencia y confirmación.

## Tecnologías utilizadas

- Java 21
- JavaFX 21
- FXML
- Scene Builder
- IntelliJ IDEA
- Maven
- Git y GitHub

## Estructura general

El proyecto utiliza una estructura organizada en diferentes paquetes:

- `controller`: contiene los controladores encargados de manejar los eventos y la lógica de las interfaces.
- `model`: contiene las clases utilizadas para representar los datos del sistema.
- Archivos `.fxml`: contienen el diseño de las diferentes ventanas de la aplicación.
